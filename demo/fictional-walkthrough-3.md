# 完整虚构演示 3 · 量入为出 Skill（极端低收入 · 刚需 >80%）

> 本演示全部人物与数字均为**虚构**，不含任何真实个人信息。

## 第 1 步 · 首用摸底（三轮）

**轮次 1 · 收入与背景**
- 工资税后 2500；无副业、无家人支持；四线小城；**租房 900/月**；单身。

**轮次 2 · 全部固定开支**
- 房租 900 · 伙食 700（自己做为主）· 交通 150（公交/电动车）· 水电网 100 · 手机宽带 50 · 杂项 150 → **刚需合计 2050**

**轮次 3 · 确认与调整**
- 无遗漏；收入稳定（无一次性收入）；现金 150（<500，愿记录）；**存款 1000 → 路线 A**（1000 连应急金零头都不够，按零基础处理）

## 第 5 步 · 储蓄状态识别

- 存款 1000 → **路线 A**。
- **阶段判定（两步法）**：
  1. 收入分档：2500 < 5000 → **阶段 1 基准**（70/20/10）。
  2. 刚需占比微调：**82% > 80% → 触发「极端情况预案」**：储蓄先降至 **5% 起步**（或暂不设）——目标是先活下去、记账不断。

## 第 6 步 · 预算 + 优化评估（重点）

**先跑「刚需占比优化评估 · 双通道」（刚需 82% 严重偏高，不能直接放弃）**：

**A. 支出端（逐项估算可省额）**
| 项 | 优化 | 可省/月 |
|---|---|---|
| 房租 | 换更便宜单间 / 找人合租 | 200 |
| 伙食 | 减少外卖，全部自己做 + 菜市场采购 | 100 |
| 交通 | 电动车替代公交（一次投入后月省） | 50 |
| 杂项 | 砍不必要的杂项 | 50 |
| **合计** | | **400** |

优化后刚需 = 2050 − 400 = **1650**（占比 66%）

**B. 收入端（三层增收评估）**
- 公司内：刚毕业，暂无明显晋升/加薪机会（标 `[需验证]`，3–6 个月后复检）。
- 公司外兼职：**愿意**，空余时间每晚 + 周末，送外卖/跑腿，估算月增 **500**（现实区间）。
- 技能变现：暂无（标假设）。

优化后总收入 = 2500 + 500 = **3000**（稳定 2500 + 兼职 500 不稳定）

**可行性结论**：支出端优化 + 收入端兼职，刚需占比从 82% → **1650/3000 = 55%**。
→ 收入 3000（仍阶段 1 档），刚需 55% → 可升级为 **过渡版 65-25-10**（刚需按实际 55%，储蓄升到 **10% = 300/月**）。

**下月预算（优化后，铁律：先划储蓄）**：

| 篮子 | 预算（元/月） | 占比 | 说明 |
|---|---|---|---|
| **储蓄（先划走）** | **300** | 10% | 第一档从 5%（125）起步，优化落地后升 10%；全部入应急金 |
| 刚需（锁定） | 1650 | 55% | 房租换租 + 伙食自做落地后 |
| 欲望 | 750 | 25% | 450 + 兼职带来的空间，仍保留社交/娱乐 |

**验证**：3000 − 300 − 1650 − 750 = 0 ✓
> 若不优化：2500 × 5% = 125/月，仅能保住"记账 + 储蓄习惯"；**优化评估的价值就是把 125 提到 300，且刚需占比降下来**。

**保险预算**：年保费参考 5–15% 年收入（36000 × 5–15% = 1800–5400/年）。小陈当前**先不配保险**（刚需占比高、应急金为零，按"先应急金后保障"顺序）；建议先攒应急金，收入与刚需进一步改善后再从刚需篮子配最基础的医疗+意外（找持牌人员）。

## 第 7 步 · 自检对比（一年后，同一口径）

| 场景 | 月储蓄 | 一年后累计 | 应急金（3 个月刚需 ≈ 4950–6150） |
|---|---|---|---|
| **当前花法**（月光） | 0 | **0** | 无 |
| **仅按 5% 起步**（不优化） | 125 | **1500** | 约 1/3 |
| **优化后**（支出省 400 + 兼职 500 → 10%） | 300 | **3600** | 约 2/3，第二年可达标 |

- 一年后对比：0 → 1500 → **3600**；且**刚需占比从 82% 降到 55%**，从"月光等死"变成"有结余 + 有方向"。
- 标注：示例估算，非保证。

## 第 8 步 · 月度复检

- 每月先确认收入增减：兼职收入**不稳定** → 某月没接单 → 储蓄比例不变（10%）、绝对值随收入降（比例口径）。
- 每 3–6 个月复检公司内加薪/晋升机会（`[需验证]`）→ 涨薪则优先提高储蓄比例。
- 应急金达标（≈ 5000）后，再谈保险与更高配置。

## 验证结论

**✅ 流程通畅**：极端情况全链路走通——阶段 1 判定、**极端预案（刚需 82% → 储蓄 5% 起步）**、**优化评估双通道（支出省 400 + 兼职增 500 → 刚需占比 82%→55%）**、过渡版 65-25-10 落地、先应急金后保障、不稳定收入比例口径复检。

**🔎 与演示 1/2 的对照**：三个假人覆盖三档处境——
- 演示 1 小李：收入中等、刚需中等偏高 → 刚需锁定 + 渐进逼近；
- 演示 2 阿婷：会存不会分 → 存量配置 + 上调储蓄档位；
- 演示 3 小陈：收入极低、刚需 >80% → **不硬存，先优化再储蓄**。
同一个 Skill，三套处理逻辑，全部按规则执行、无混算。
